# Motion sites portfolio

Seven concept websites with scroll and cursor motion, one per local-business niche. Every brand is fictional.

| Folder | Niche |
|---|---|
| `ganisthom/` | **Client work:** concept redesign for Ganisthom Consulting (official site: ganisthom.com) |
| `zest-riot/` | Drinks brand |
| `honeywild/` | Florist and wedding stylist (bee follows the cursor) |
| `ember-rye/` | Café and restaurant |
| `lune/` | Beauty and skincare clinic |
| `halden-house/` | Interior designer and kitchen showroom |
| `bunch-market/` | Supermarket |
| `little-flame/` | Home-based business |

Each site is a single self-contained `index.html` with no build step. `index.html` at the root is the portfolio home page that links to all seven.

## Put it live with GitHub Pages

1. Repo **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then **Save**.
3. After a minute the site is at `https://<your-username>.github.io/<repo-name>/`.
